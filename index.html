Curious? Let's Break it Down
What are Validator Nodes?

Validator Nodes are community-run nodes that form the backbone of the oracle network. They don't collect data themselves — instead, they validate and secure signals from decentralized weather stations. By recomputing content hashes (CIDs), checking timestamps and device signatures, and reaching consensus with other nodes, they ensure only authentic data is anchored on-chain.

What does a Validator Node do?

Validator Nodes check and process data packages uploaded daily by weather stations, verifying accuracy and integrity before submitting attestations on-chain. Once a quorum is reached, the data becomes part of the immutable oracle layer. Nodes can run in multiple modes — from browser-based Web UI to CLI or VPS — making participation both accessible and reward-driven.
